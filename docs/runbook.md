# Operations runbook

If fallback rate spikes, first pause unhealthy destinations, then verify HTTPS and allowed-host configuration, route/drama publication state, device/country rules, and validity windows. Keep a universal destination configured where the partner permits it.

If click persistence fails, the redirect path should continue in degraded mode and alert operations. Never expose the destination through a public JSON endpoint. If a CPS URL or token leaks, disable the destination, rotate it at the provider, replace the encrypted value, invalidate relevant caches, and review access/audit logs.
